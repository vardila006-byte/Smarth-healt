Smarth-healt 

Smarth-healt es una aplicación móvil diseñada para brindar apoyo a las personas con Alzheimer y a sus cuidadores. 

Características
* Interfaz facil e intuitiva.
 * Pantalla de inicio de sesión segura.
 * Diseño con colores suaves para evitar la sobreestimulación visual

Tecnologías utilizadas
 * Kotlin -> Lenguaje de programación principal.
 * Jetpack Compose -> Para el diseño de la interfaz gráfica.
 * Android Studio -> Entorno de desarrollo.

Estado del proyecto
En desarrollo. Actualmente cuenta con las pantallas de SplashScreen y Login.
